# vaultipv4

Vault identifiers and ipv4 tokens for idempotent workflows.

**Site:** https://theworker02.github.io/vaultipv4/

## Install / run

```bash
git clone https://github.com/theworker02/vaultipv4.git
cd vaultipv4
node src/cli.js
node --test
```
